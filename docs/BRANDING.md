# Identity

## Name

**Pace Beads** — the beads used to keep track of distance while walking.

- Repository: `x-vlad-x/pace-beads`.
- Application ID: `io.github.x_vlad_x.PaceBeads`.
- Application name: `Pace Beads`; generic description: `Step Counter`.
- Generic description in German: `Schrittzähler`; in Russian: `Шагомер`.

The name consists of two ordinary nouns, is ten characters including the space, relates to walking, and suggests a physical object for an icon. It follows the direction of the [GNOME naming guidelines](https://developer.gnome.org/hig/guidelines/app-naming.html). It avoids toolkit and platform names in the displayed application name.

Exact-name searches on 2026-10-31 did not identify a matching app in the searched GNOME, Flathub and GitHub results. Related navigation products and an Android app called PaceCount Bead exist. These bounded searches do not establish global uniqueness, trademark clearance, domain availability or future repository availability.

## Icon

Original, editable SVG sources are in `../design/`:

- `pace-beads.svg`: full-color app icon on a transparent 128 × 128 canvas.
- `pace-beads-symbolic.svg`: simplified monochrome 16 × 16 companion.

The metaphor is a loop of cord carrying counting beads, with one separated bead suggesting progress. Blue and teal surfaces, a warm accent bead, and a subtle dark front edge provide a simple physical appearance. There are no letters, numbers, brand marks or external images.

The [GNOME app-icon guidelines](https://developer.gnome.org/hig/guidelines/app-icons.html) call for a recognizable metaphor, restrained detail, a 128-pixel design area and a symbolic version.

The icon does not imply that the interface requires manual bead counting: steps are counted automatically by the sensor.
